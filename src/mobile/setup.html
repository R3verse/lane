Only install the certificate if its name and fingerprint match. A trusted root can authorize certificates; remove it when you stop using this Lane computer.

2. Trust it on your device

iPhone / iPad
  1. Download the certificate in Safari. Allow the profile download.
  2. Open Settings → General → VPN & Device Management, select the downloaded Lane profile, open its certificate details, verify its fingerprint against the computer, then install it.
  3. Open Settings → General → About → Certificate Trust Settings and enable full trust for the matching Lane certificate.
Android

In device Settings, search for Install a certificate → CA certificate and select the downloaded file. Names vary by manufacturer; a screen lock may be required.

Another Windows computer

Open the certificate, choose Install Certificate → Current User → Place all certificates in the following store → Trusted Root Certification Authorities. Verify its details before finishing. Restart the browser if necessary.

Use your device’s certificate settings to remove the Lane root later. Lane never installs trust automatically.

Already paired over HTTP? Before disabling HTTP, use Settings → Recovery & HTTPS on the old page to save a password-protected browser backup. Restore it on the HTTPS page to keep your identity and conversations. Pairing again creates a separate identity.

Already trusted, but Safari still warns?

A private Lane certificate can be trusted without buying a public certificate. Installing the profile and enabling Full Trust are separate steps. If both are complete:

  1. Check that the trusted certificate is {{CA_NAME}}, with the root fingerprint shown above and on the computer. Another Lane installation can have a different authority.
  2. Use the exact {{SECURE_URL}} address above. The certificate must cover that IP address; an old bookmark may point to another computer.
  3. Check that the phone and computer use the correct date and time. Close the old Safari tab and open the secure address in a fresh tab.
  4. If the warning remains, open Safari’s certificate details and compare its issuer, validity dates and address with Lane’s Settings. Do not treat bypassing the warning as a verified connection.

Lane 0.8 fixes the “Cross-site requests are not allowed” error when opening HTTPS from this setup page. That error is separate from certificate trust. The website cannot automatically inspect or repair iPhone’s trusted certificate store.
