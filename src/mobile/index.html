Keep Lane close

First open your verified HTTPS address using Settings → Recovery & HTTPS. Add the secure page to your Home Screen.

  1. On iPhone or iPad: open Lane in Safari, open the Share menu, then choose Add to Home Screen. Keep Open as Web App enabled if shown, then tap Add.
  2. On Android: open the browser menu and choose Install app or Add to Home screen, if available.
  3. Open the Lane icon. Keep this computer running and use the same local network.

Your Home Screen app may have separate browser storage. If it asks you to pair again, use Recovery & HTTPS to save an encrypted backup in the original Safari tab, then restore it in the Home Screen app to keep your existing message identity.

This shortcut does not add background delivery, SMS or iPhone vibration. The computer must be reachable to load Lane.
