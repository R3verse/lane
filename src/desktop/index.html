A QUICK CONNECTION CHECK

Let's get you connected.

  1. Use the same home or office network.

    Your computer can use Ethernet and your phone can use Wi-Fi. Guest Wi-Fi may keep devices apart.

  2. Allow Lane on private networks.

    If Windows Firewall asks, allow Lane on Private networks. On a managed computer, your IT administrator may need to allow incoming TCP ports 47831 (setup) and 47832 (HTTPS).

  3. Keep Lane running and the computer awake.

    You can close this window to the system tray. Files wait on your phone if the receiver is unavailable.

  4. Scan a fresh QR code if the address changed.

    The browser remembers this computer at its local address. Private browsing, cleared site data or a new IP address may require pairing again.

Use Settings → Secure connection to install and verify this computer’s certificate, then connect over HTTPS. Keep the phone’s page open until each transfer finishes.
